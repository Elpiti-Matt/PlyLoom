# Возможности PlyLoom 0.8.0

[README](../README.ru.md) содержит полный перечень возможностей. Ниже — как ими пользоваться. Все картинки здесь учебные: они объясняют поведение, но не воспроизводят интерфейс пиксель в пиксель.

## Выбрать подходящий режим

![Два уровня листов и отдельные режимы](images/views-ru.svg)

| Задача | Режим и действие |
| --- | --- |
| Подробно редактировать диаграмму | **Листы**: двигать узлы, выбирать их, раскрывать через «+» |
| Посмотреть весь проект | **− Все листы** в правом верхнем углу редактора |
| Переставить лист целиком | В обзоре тянуть за заголовок; внутренние координаты узлов сохраняются |
| Переставить узел в обзоре | Тянуть сам узел; движение ограничено его листом и не меняет другие появления |
| Вернуться к редактированию | **+** в углу нужного листа |
| Сравнить несколько диаграмм | **Разворот**: выбрать 2–6 листов и пропорции |
| Рассмотреть структуру по слоям | **Стопка**: «Построчно» или «Узлы и связи», группировка по типу/тегу |
| Увидеть каждую сущность один раз | **Все на один лист**: отдельные сохраняемые позиции, общие текст и атрибуты |
| Перейти по структуре проекта | **Оглавление**: схема или список |

Для обзора используйте фон и колесо для перемещения, нижние кнопки или Ctrl/⌘ + колесо для масштаба. Два пальца тоже меняют масштаб. **Вписать все листы** возвращает весь проект в поле зрения. Масштаб обзора сохраняется при переходах «− / +» в текущем сеансе.

## Оставить только связи нужного листа

В обзоре включите **Только для выделенного листа** и нажмите заголовок листа. Его название появится над обзором. Все листы и их внутренние связи остаются на месте; межлистовые связи, не затрагивающие выбранный лист, скрываются.

**Между листами** управляет обычными межлистовыми отношениями. **Один ID** — золотыми линиями между появлениями одной сущности. При включённом фокусе золотые линии идут от выбранного листа ко всем остальным появлениям этого ID. Снятие отметки «Только для выделенного листа» возвращает общий обзор связей. Эти настройки не меняют данные проекта.

## Типы, теги и фильтры

В **Типы → Листы** сначала находятся теги, затем типы листов, затем сами листы. В каждом разделе можно добавить запись. У листа один тип и несколько тегов. Они помогают классифицировать листы и группировать стопку; тип листа не запрещает никаких типов узлов или связей.

Кнопка **Фильтр** на панели инструментов открывает панель над картой; число на кнопке — сколько условий включено. В панели:

- **Поиск** — строка вверху панели и пять областей, которые можно выключать: **имя**, **тело**, **теги** узла, **лист** и **атрибуты** (значения атрибутов узла). Поиск идёт по вхождению без учёта регистра. Область «лист» находит узлы, лежащие на листе с подходящим названием или тегом. Несколько слов через пробел означают И: найтись должно каждое слово, каждое — в любой из отмеченных областей. Между областями одного слова — ИЛИ, со остальными условиями — И. Пустая строка или ни одной области не фильтруют. **Enter** переходит к следующему совпадению (строка сообщает «Совпадение N из M») и запоминает запрос — последние шесть предлагаются в строке поиска. Полоса листов помечает листы, где что-то нашлось, и приглушает пустые; кнопка **Только найденные** оставляет в списке только их. Сами листы фильтр не скрывает: на них держится геометрия обзора, оглавления и раскладок.
- **Типы узлов** и **Типы связей** — отметки только для типов, которые есть в проекте, с числом объектов. У каждой группы свои **Выбрать все / Выключить все**.
- **Атрибуты** — «+ Условие по атрибуту». Число и дата — диапазон «от / до» включительно; текст и ссылка — «содержит» без учёта регистра; да/нет и список — набор значений; множественный выбор — набор вариантов с переключателем **любой из / все выбранные** (по умолчанию «любой из»: узлу достаточно одного отмеченного варианта; «все выбранные» требует всех сразу). У каждого атрибута есть два отдельных состояния: **не заполнено** (атрибут есть, значение пустое) и **нет атрибута**. Возле значений — сколько узлов их имеют.

Разные условия действуют вместе (И), отметки внутри одного условия — любая из них (ИЛИ). Пустое условие ничего не фильтрует и помечено «не задано». Связь видна, только если виден её тип и оба конца.

Переключатель **Скрывать / Приглушать** решает, что делать с остальным. **Скрывать** (по умолчанию) — отфильтрованное не рисуется ни в одном виде, включая ссылки за границей листа и счётчики оглавления; на больших картах это быстрее. **Приглушать** — те же объекты остаются на местах бледными, их можно выбрать; удобно на небольших картах. В обоих режимах остальные объекты не сдвигаются, состав карты и экспорт не меняются.

Когда панель свёрнута, над картой видна строка «Фильтр: показано N из M узлов · скрыто связей: K · на листе: a/b» (в развороте — «в развороте», в стопке — «в стопке», в обзоре — «листов с узлами») с тем же переключателем и кнопками **Настроить** и **Показать всё**. На телефоне строка короче: только главная фраза и кнопки.

Узел, который вы создаёте, открываете (из панели листа, связей или проверки проекта) или меняете так, что он перестаёт подходить, остаётся на экране поверх фильтра, пока фильтр не изменится. Строка показывает «вне фильтра оставлено: N», всплывающее сообщение объясняет почему. Так же ведёт себя связь скрытого типа, которую вы создали. Сам фильтр при этом не меняется.

**Оптимизировать расположение** при активном фильтре учитывает и двигает все узлы, включая скрытые, — иначе скрытые оказались бы под видимыми. Сообщение о результате напоминает об этом.

## Атрибуты: определение и значение

![Словарь атрибутов и значения общего узла](images/attributes-ru.svg)

1. Откройте **Типы → Атрибуты**. Добавьте определение, например «Стоимость, ₽», выберите **Число**, сохраните типы.
2. Выберите узел. В его свойствах добавьте этот атрибут и задайте значение. Можно раскрыть узел кнопкой **+** и сделать это рядом с текстом.
3. Найдите тот же ID на другом листе: значение общее. Координаты появлений остаются независимыми.
4. Скачайте `.plyloom`, чтобы сохранить определения и значения вместе с картой. Правки атрибутов участвуют в отмене/повторе.

| Тип данных | Пример значения | Что учитывать |
| --- | --- | --- |
| Текст | «Проверить источник» | Краткая заметка или описание |
| Число | `125.5` | Единицы лучше указать в названии определения |
| Да/нет | `true` или `false` | Незаданное значение отличается от «нет» |
| Дата | `2026-09-09` | Корректная календарная дата |
| URL | `https://example.com` | Ссылка с http/https |
| Список вариантов | «Черновик» | Один вариант из заданного списка |
| Множественный выбор | «рисование, музыка» | Несколько вариантов из списка; отмечаются чекбоксами. Пустой список считается «не заполнено». Файл с таким атрибутом не откроется в версиях до 0.7.0 |

В JSON определения лежат в `types.attributes`, значения — в `attributes` узла. `null` означает «атрибут добавлен, значение не задано»; отсутствие ключа — «атрибут к узлу не добавлен». Значения в таблице — примеры синтаксиса, не сведения о вашем проекте.

## Связи и импортированные диаграммы

![Четыре шага чтения линий](../src/assets/help/lines-ru.gif)

*[Открыть неподвижную иллюстрацию](../src/assets/help/lines-ru.png). Золотые линии не являются отдельными отношениями: они выводятся из членств одного ID.*

Внутри листа все отношения сплошные, между листами пунктирные. Текстовый тип связи передаёт смысл: «зависит от», «наследует от», «реализует» и другие. Собственные типы создаются в **Типы → Связи**; штрих линии там не настраивается.

Импорт draw.io, JSON Canvas и BPMN DI добавляет листы после предпросмотра. Базовые формы, размеры и позиции сохраняются; у draw.io/BPMN также сохраняются точки маршрутов. Можно редактировать импортированные узлы и связывать их с другими листами. Прямого импорта Miro нет. Сложные фигуры, группы, маркеры и оформление могут упрощаться; [FORMAT](FORMAT.md) описывает ограничения. Сплошные линии меняют визуальные соглашения BPMN/UML, поэтому для смысла важны тип и подпись.

## Дополнительные инструменты

**Лимита узлов на листе нет.** Размер листа сам по себе не ошибка: большой лист читают фильтром и поиском, а «Справка → Проверить проект» только отмечает заметкой лист, который выделяется на фоне остальных листов этого проекта. Делить лист стоит, когда он отвечает на два разных вопроса: в панели листа выберите признак — атрибут, теги или тип узла — и нажмите **«Разложить»**. На каждое значение получится свой лист с этим значением в названии; узел с несколькими значениями (множественный выбор или несколько тегов) встанет на несколько листов, узлы без значения соберутся на листе «Без значения». Координаты, оформление, связи и членства на других листах сохраняются; «Отменить» возвращает прежнюю карту.

**Проект → Другие форматы и примеры** открывает CSV и встроенные учебные карты. Пара `nodes.csv` / `edges.csv` описывает узлы и связи; старый JSON также читается. **Справка → Проверить проект** показывает замечания к структуре и членствам. Текст узлов поддерживает безопасное подмножество Markdown.

## Сохранение и ограничения

Автосохранение хранит текущую карту в браузере. Файл `.plyloom` нужен для переноса между устройствами и резервной копии. draw.io/Canvas — представления, которые не сохраняют всю модель PlyLoom. Камера, активный несохранённый фильтр и раскладка стопки относятся к сеансу; расположение листов, узлов и All-to-1 входит в `.plyloom`.

Оптимизация листа и разворота меняет их координаты; отмена возвращает прежние. Оптимизация стопки меняет только её вид, All-to-1 — его отдельные позиции. В обзоре есть вписывание всех листов; автоматической расстановки целых листов пока нет.

Фиксированные лимиты числа объектов сняты. Большие импорты требуют подтверждения; технический предел входных/распакованных данных — 128 МиБ. Скорость зависит от устройства и плотности связей. Поддержка импорта базовая, а не универсальная 1:1. [Ручная приёмка](QA-MANUAL.md).


## Сохранённые виды, умные листы и большие карты

В **Фильтр → Сохранённые виды** задайте имя и сохраните текущие условия, режим «Скрывать / Приглушать» и набор листов. Вид можно открыть, переименовать, заменить текущими настройками или удалить. Он входит в `.plyloom`. История шести запросов остаётся в этом браузере; «Очистить историю» не меняет карту. Совпадения подсвечиваются в имени, тексте и значениях атрибутов карточки. Строка статуса учитывает и оглавление.

**Создать умный лист** строит состав из узлов всего проекта по текущим условиям. Измените подходящий узел — состав пересчитается. Умный лист не заменяет обычные членства, поэтому сущность не потеряется, если перестанет соответствовать запросу. Менять состав вручную нельзя; обновите запрос в диалоге видов или выберите в свойствах **Сделать обычным листом** для фиксации результата. Условие поиска по листу учитывает только обычные листы, без рекурсии.

Автосохранение перешло на IndexedDB: прежняя запись переносится автоматически, а запись нового снимка выполняется в простое. Дождитесь «сохранено»; при ошибке скачайте карту. Крупный native JSON и оптимизация раскладки выполняются встроенным воркером с отменой; браузер без этой возможности использует основной поток.

В листе и All-to-1 более 500 объектов при масштабе меньше 35% рисуются Canvas; на читаемом масштабе возвращаются карточки. Щелчок по узлу или Enter в поиске открывает читаемый фрагмент. Текст, специальные маркеры и наконечники в таком уменьшенном виде упрощены; полная модель не меняется. Края сцены отсекаются с запасом, выбранные и редактируемые карточки удерживаются. В обзоре крупные листы получают компактную SVG-сцену; её геометрия повторно используется между фиксациями камеры. Во время медленных жестов временно убираются подписи, сниппеты и тени. Это не обещание одинаковой частоты кадров на всех устройствах.
