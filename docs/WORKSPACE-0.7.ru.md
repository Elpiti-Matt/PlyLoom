# PlyLoom — рабочая версия 0.7.1 (история)

> Историческое описание интерфейса 0.7.1. Изменения 0.8.0 и текущая приёмка описаны в FEATURES, FORMAT и QA-MANUAL.


Режим **Листы** объединяет редактор одного листа и свободный обзор всех листов. «− Все листы» открывает обзор, «+» в углу листа возвращает к редактированию. Листы перемещаются за заголовки, узлы — внутри своих листов. `overviewPos` листа независим от `node.pos` и входит в сохранение/историю.

В обзоре **Только для выделенного листа** оставляет его межлистовые отношения и золотые линии ко всем другим появлениям общего ID. Фокус меняется нажатием заголовка; **Между листами** и **Один ID** управляются отдельно. Все листы и локальные связи остаются видны. В **Фильтр** две пары кнопок выбирают/выключают все типы узлов и связей независимо; там же условия по атрибутам и переключатель **Скрывать / Приглушать** (с 0.7.0-rc.7; в rc.6 только скрытие, раньше только приглушение).

**Все на один лист / All-to-1** показывает по одному появлению сущности, позволяет редактировать общие текст/атрибуты и независимо расставлять узлы. Разворот сравнивает 2–6 выбранных листов. Стопка имеет «Построчно» / «Узлы и связи», все узлы, группировку и свою оптимизацию. Словари типов/тегов листов, базовый импорт нотаций и типизированные атрибуты доступны во всех соответствующих редакторах.

Промпты, JSON-примеры и справка согласованы с **PlyLoom v3**: определения атрибутов, значения всех шести типов, классификация листов и общий ID. Команда `npm run ai:docs` пересобирает скачиваемые файлы, тест проверяет совпадение с приложением. README содержит перечень функций и иллюстрации; [FEATURES](FEATURES.ru.md) показывает работу с ними.

Формат — [FORMAT](FORMAT.md), производительность отрисовки и её проверка — [PERFORMANCE](PERFORMANCE.ru.md).

Импорт сохраняет базовую геометрию, но не произвольную графику редакторов; прямого импорта Miro нет. Сплошные внутренние линии меняют визуальную семантику BPMN/UML, поэтому смысл сохраняется в типах/подписях. `.plyloom` — формат продолжения работы. Фильтры, камера и расположение стопки — состояние сеанса. Визуальная проверка приложения браузером заблокирована средой; физические устройства и внешний редактор вручную не проверялись.
