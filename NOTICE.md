# Source and asset notices

The application is derived from the user-supplied ZIP containing React/TypeScript Atlas source. The two supplied HTML files were inspected as earlier compiled prototypes; they are not the editable source of this release.

The depot dataset is retained as a fictional teaching scenario. Its figures and domain rules have not been independently verified. The coffee dataset is a newly authored fictional scenario and carries that provenance in its node bodies.

The photograph `boiler.jpg` from the supplied ZIP has no accompanying attribution or license statement, so it is omitted from this release. No replacement stock photograph is claimed.

Bundled runtime dependencies retain their licenses in `THIRD_PARTY_NOTICES.txt`, also embedded in the release HTML. Historical papers are linked, not redistributed.

The product is now named **PlyLoom**. Since 0.7.0-rc.7 the copyright line in `LICENSE` and `THIRD_PARTY_NOTICES.txt` reads PlyLoom contributors; this renames the holder line of the same MIT terms and grants nothing new. File-format and storage identifiers from Atlas and Plyra (`plyra` notation, `plyra*` draw.io attributes, `atlas.*` storage keys) are retained on purpose, so older files keep opening.
