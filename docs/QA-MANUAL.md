# Ручная проверка PlyLoom 0.8.0

Автоматические тесты покрывают модель, DOM в jsdom, транзакции IndexedDB и код воркера, извлечённый из готового HTML. Ничто из этого не заменяет настоящий браузер и настоящее устройство: жесты, инерцию прокрутки, экранную клавиатуру, шрифты, печать и перенос файлов через внешние редакторы проверяют руками по списку ниже. Записывайте фактические дату, браузер, устройство, размер окна и результат.

`npm run test:browser` проверяет DOM и native IndexedDB; `npm run test:release` — именно собранный автономный HTML, CSP, импорт через blob-воркер, Canvas и 1440/390 px, со снимками в `.qa/release/`. `npm run test:perf` проверяет структуру сцены и кадровый бюджет. Эти команды доступны в необязательной CI-задаче.

## Среды

| Среда | Проверить |
| --- | --- |
| Chrome и Firefox, 1366 × 768 и 1440 × 900 | Все режимы, клавиатура, импорт/экспорт, сохранение |
| Safari macOS | Локальный HTML, хранилище, загрузка файлов |
| iPhone Safari и Android Chrome, 360–412 CSS px | Портрет/альбом, экранная клавиатура, фон, pinch, начало жеста на узле |
| Планшет, 768 и 1024 CSS px | Панели, разворот, обзор, изменение размера |
| Увеличение текста до 200 % | Доступность обязательных кнопок, длинных названий и форм |

## Основной маршрут

1. Открыть `demo/index.html` с учебной картой. Проверить ошибки консоли и автономное открытие. Пользовательские карты перед обновлением экспортировать в `.plyloom`.
2. В **Листах** передвинуть узел. Через его «+» изменить имя, текст и атрибут; проверить общий ID на другом листе, независимые координаты и отмену/повтор.
3. Нажать **− Все листы** справа сверху. В **Обзоре листов** проверить все листы и пустые листы, подписи, базовые импортированные формы, внутренние/межлистовые/золотые связи. Через **+** открыть нужный лист и вернуться к прежней камере обзора.
4. В обзоре переместить лист за заголовок: внутренние координаты узлов сохраняются. Передвинуть узел: меняется только появление на этом листе; на границе движение ограничено, членство не переносится. Проверить одно действие отмены и повтор.
5. Во время движения в обзоре нажать Escape, прервать касание системным жестом или начать pinch. Незавершённое перемещение не должно записываться. Проверить фон/колесо, Ctrl/⌘ + колесо, кнопки масштаба, два пальца и «Вписать все листы».
6. В **Развороте** пройти 2–6 листов и разные пропорции; проверить межлистовые линии к реально видимым узлам и боковые ссылки за пределы вида. На телефоне активен один лист. Перестановка и оптимизация сохраняют состав листов.
7. В **Все на один лист / All-to-1** проверить одно появление на ID. Перемещение/оптимизация не меняют позиции исходных листов, редактирование текста/атрибутов общее. Сплошные/пунктирные линии отражают исходные членства.
8. В **Типы → Листы** создать тег, тип и лист, назначить ровно один тип и несколько тегов. Тип листа не исключает узлы и связи. В **Фильтр** выключить тип: соответствующие объекты исчезают во всех видах (лист, разворот, обзор, стопка, оглавление, All-to-1), остальные не сдвигаются; после «Свернуть» над картой строка «показано N из M», **Показать всё** возвращает всё. Переключить **Приглушать**: те же объекты видны бледными на своих местах во всех видах; **Скрывать** снова убирает их.
9. В **Типы → Атрибуты** проверить текст, число, да/нет, дату, URL, список вариантов и незаданное значение. Назначить значения из свойств и через «+» узла, сохранить, отменить/повторить.
10. В **Стопке** проверить «Построчно» / «Узлы и связи», более десяти узлов, все выбранные листы, группировку по типу/тегу и независимую оптимизацию. В **Оглавлении** проверить схему, ручной переход к списку и фокус связей.
11. Создать пустой проект, лист, узел и межлистовую связь. Проверить русские/английские формы, закрытие без изменений, отмену удаления и возврат прежнего проекта.
12. Импортировать примеры draw.io, Canvas и BPMN DI из `examples/import/`. Сопоставить базовую геометрию с исходными редакторами и прочитать ограничения предпросмотра. У сложных фигур и специальных маркеров нет обещания 1:1; внутренние линии нормализуются в сплошные.
13. Открыть `.plyloom` повторно: сохранить ID, членства, атрибуты, словари, геометрию, `overviewPos` и `flatPositions`. Ошибочный файл (`data/broken.json`) должен оставить прежнюю карту. Повторно выбрать тот же файл, проверить CSV с двумя входными файлами.
14. Проверить экспорт draw.io/Canvas во внешних редакторах. Эти проекции не сохраняют всю модель PlyLoom. Экспорт в дерево для v3 заблокирован. Перезагрузить страницу после редактирования; при недоступном хранилище проверить понятное сообщение о работе только в памяти.
15. Клавиатура: Tab, фокус и Escape в диалогах/панелях; стрелки и Enter на заголовках/узлах обзора. На телефоне проверить длинные названия, нижние кнопки, форму с открытой клавиатурой, поворот и отсутствие прокрутки всей страницы при жестах листа.

16. В **Фильтр** нажать каждую из четырёх групповых кнопок, включая пользовательские типы. Выключение узлов не меняет отметки связей и наоборот. Объекты скрываются без перемещения остальных. Открыть скрытый узел из панели листа — он виден, остальные узлы его типа скрыты, строка пишет «вне фильтра оставлено: 1»; любое изменение фильтра снова скрывает его. В строке фильтра проверить счётчик по виду: на листе, в развороте, в стопке и в обзоре («листов с узлами»).
16а. Атрибуты: создать атрибуты всех семи типов, заполнить у нескольких узлов, у одного оставить пустое значение, у другого не добавлять атрибут. В **Фильтр** добавить условия: диапазон числа и даты, «содержит» для текста, значения списка и да/нет, «не заполнено», «нет атрибута». Сверить состав с ожиданием (И между атрибутами, ИЛИ внутри). Изменить у видимого узла значение так, чтобы он перестал подходить, — узел остаётся. Сохранить `.plyloom` — файл не зависит от фильтра. На телефоне панель прокручивается и не перекрывает карту целиком; строка фильтра — не больше двух строк. Проверить на встроенных примерах: в «Маленькой обжарке» есть «Основание» и «Затрагивает», в «Разработке» — «Состояние», «Области», «Оценка, дней» и «Контрольная дата».
16б. Множественный выбор: создать атрибут этого типа с 3–4 вариантами, отметить у одного узла два варианта, у другого один, у третьего ни одного. В карточке варианты отмечаются чекбоксами, отмена/повтор возвращают прежний набор. В **Фильтр** добавить условие по нему: «любой из» оставляет узлы хотя бы с одним отмеченным вариантом, «все выбранные» — только с полным набором; узел с пустым списком ловится отметкой «не заполнено».
16в. Поиск: ввести часть имени узла — остаются только совпадения, счётчик условий увеличивается на единицу. Выключить область «имя» — результат меняется. Проверить области «тело», «теги», «лист» (находит узлы по названию листа и по его тегу) и «атрибуты» (находит узлы по значению атрибута). Ввести два слова, которые встречаются в разных областях одного узла, — узел остаётся; добавить слово, которого нет нигде, — список пустеет. **Enter** в строке поиска обходит совпадения по кругу и пишет «Совпадение N из M»; после этого прежний запрос предлагается в строке. Полоса листов помечает листы с совпадениями и приглушает пустые, кнопка **Только найденные** оставляет в списке только их и перелистывание идёт по сокращённому списку. **Показать всё** очищает строку, возвращает все области и все листы в список.
16г. Лимита листа нет: в панели листа нет поля «Лимит узлов» и полоски «Заполненность», а счётчики в списке листов, в заголовке листа и в развороте показывают одно число без красного. В **Справка → Проверить проект** нет замечаний «при лимите» и «близок к лимиту»; на карте, где один лист заметно больше остальных, есть заметка со ссылкой на фильтр и поиск. Раскладка: в панели листа выбрать признак и нажать **«Разложить»**. По атрибуту-списку получается по листу на каждое встреченное значение плюс «Без значения», названия листов содержат значение, сообщение внизу пишет число листов. По множественному выбору узел с двумя вариантами оказывается на двух новых листах с теми же координатами. По тегам и по типу узла — то же самое. Проверить, что узлы, связи и членства на других листах на месте, «Отменить» возвращает прежнюю карту, а повторная раскладка того же листа по одиночному выбору сообщает, что раскладывать не на что (по множественному выбору и тегам повтор допустим и снова делит лист). На телефоне выпадающий список и кнопка не выходят за панель.
17. В обзоре включить **Только для выделенного листа** на карте с общим ID минимум на трёх листах: золотые линии должны идти ко всем его появлениям. Выбирать листы заголовками мышью и клавиатурой, независимо переключать «Между листами» / «Один ID». Внутренние связи и все листы остаются.
18. В справке проверить **PlyLoom v3**: копирование промпта и скачивание обоих примеров, импорт определений/значений атрибутов шести типов; сравнить с docs/AI-PROMPT и data/ai-example. Учебная GIF про ИИ также должна показывать v3.

## Оптимизация и дополнительные сценарии

Для листа, разворота и All-to-1 проверить уменьшение наложений на конкретной карте, сохранение результата, отмену целиком и отмену расчёта. В стопке проверить только её собственную раскладку. В обзоре целых листов есть вписывание; автоматическая оптимизация их положения не реализована.

Проверить FAQ, легенду мышью/касанием/клавиатурой, включаемые учебные GIF, копирование стандарта для ИИ и скачивание примера при отказе буфера. Учебные иллюстрации не являются снимками текущего интерфейса. Смена языка не должна переписывать пользовательские данные.

После публикации отдельно открыть фактический URL Pages и проверить версию, загрузку HTML и сохранение своей карты. Для каждого дефекта записать ожидаемый и фактический результат; использовать синтетические данные. Блокирующие ошибки сохранения/импорта должны быть устранены до выпуска стабильной версии.


## Приёмка 0.8.0

17. Начать со старого сохранения в localStorage, открыть новую версию, дождаться «сохранено», перезагрузить. ID, членства и атрибуты должны совпасть; прежний ключ остаётся. Отказ записи не должен уничтожать последнюю удачную версию. Незавершённое сохранение при закрытии должно предупреждать, если браузер разрешает предупреждения.
18. Сохранить вид с фильтром и разворотом, изменить настройки, открыть вид. Проверить переименование, замену, удаление, undo/redo и перенос через `.plyloom`. Создать умный лист; изменить имя/атрибут узла так, чтобы он вышел из запроса и вернулся. Обычный лист и общий ID сохраняются. Проверить преобразование в обычный лист.
19. Поиск: имя, тело, атрибуты, кириллица и буквальные спецсимволы; подсветка и Enter. Перезагрузить и проверить историю, затем очистить. В оглавлении сверить счётчик листов.
20. 1 000 и 10 000 узлов: проверить Canvas на мелком масштабе, щелчок и поиск, переход к DOM, панораму через границу отсекаемой области, отмену перетаскивания, связь за экраном с пересекающей экран кривой. Проверить приглушение в Canvas и компактном обзоре. На повёрнутых импортированных фигурах края не должны исчезать преждевременно.
21. Native JSON больше 1 МиБ и оптимизация проекта больше 300 узлов: воркер, прогресс и отмена. Файл больше 20 МиБ и проект больше порогов требуют подтверждения; отказ оставляет текущую карту. Повторить с недоступным Worker, а draw.io/BPMN — с отменой после чтения.
22. Проверить 1440/390 px из `test:release`, затем физические устройства из таблицы. Убедиться, что кнопка увеличения Canvas, история и сохранённые виды доступны с клавиатуры; импортный диалог удерживает фокус и закрывается Escape.
